Run of is how many identical characters in a row count as a repeat (2 = dubs, 3 = trips, 4 = quads…).

Substrings

Ignore TLD matches only the part before the first dot. Include TLD matches the name with its dots removed, so example finds exampl.e. A term containing a dot (foo.co) always matches against the full name, dots and all. This matches both foo.com and foo.co.com.

Structure

L letter · C consonant · V vowel · N number · - hyphen · * any · any other character matches itself. Vowels are aeiou, so y counts as a consonant. Patterns match the whole name, so CVV-CVCN gives foo-bar2 and LL*N gives de-4. Add several to match any of them.

Upload a Namecheap CSV export (Market Auction, Market Buy-Now, or a bulk search "Beast Mode") result. The parser auto-detects the table type from the column headers, case insensitively. Use the filters above to narrow results, then export the filtered set.

Tri-toggles: Yes = must have, No = must not have, Any = don't care. For TLDs and substrings, press Enter to add tags.

TLD dropdown: lists every TLD found in the uploaded file with its row count, sorted by frequency. Pick one and hit + Inc or - Exc to add it as a tag.

Renewal prices: auction exports carry a renewPrice per row and that always wins. Buy-now exports don't, so the Renew $ column falls back to Namecheap's published renewal price for the TLD. Premium domains renew above their TLD's standard rate, so this isn't always gospel.

Keyboard Patterns: Analyzes domain names against a US QWERTY layout. "Same Row" means every character sits on one keyboard row. "Adjacent %" measures how many consecutive key-pairs are physically next to each other.
