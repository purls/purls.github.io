Note: This is a playable demonstration of one-time passcode systems. No emails are sent, and any email addresses input are not stored or used.

The math: A 6-digit code has 1,000,000 possibilities. Without repeats, each guess has a 1 in (1,000,000 minus prior guesses) chance, so one code takes 500,000 guesses on average. Nobody gets there before it expires, so in practice every guess is a fresh 1 in 1,000,000.

Why it works: Real services expire codes after a few minutes and lock you out after a handful of wrong tries. Five guesses gives 0.0005% odds. This page is generous and never locks you out, yet the code still expires in 10 minutes and a fresh one wipes your progress.

Is it real? Yes. The code comes from crypto.getRandomValues with rejection sampling, so every code is equally likely.
