    This is one-dimensional bin packing. Rows are bins, the container width is the bin capacity. The search is branch and bound, so the row count is the true minimum unless the summary says it is unproven.

    Width, Padding, Gap: all in the same unit as the item sizes. Padding is the total added to each item, left plus right. Gap is the space between neighbors. A row fits when item sizes plus padding plus gaps stay within the width.

    Character count: an item is as wide as its text, so the unit is one monospace character. Divide pixel sizes by the glyph width to convert, e.g. 9.6px for JetBrains Mono at 16px. The defaults are the link box on the home page.

    Trailing value: the size is the number ending the line, e.g. Crate A, 12.5 or Crate A 12.5. Set padding and gap to 0 for plain packing.

    Order: the items in sequence. Placed in a wrapping container they break into the rows shown. Items wider than the container get a row of their own.
