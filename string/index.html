Character counts differ by definition. Characters is the JavaScript string length in UTF-16 code units, which is what most editors and APIs report. Code points counts Unicode scalar values. Graphemes counts what a person sees as one character, so a flag emoji or an accented letter built from combining marks counts once.

Positions are 1-based lines and columns, with columns in UTF-16 code units. Click a position to select it in the editor. For transforming text, use Advanced Replace.
