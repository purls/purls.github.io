Structure

L letter · C consonant · V vowel · N number · S symbol · * any · any other character matches itself. Prefix with \ for a literal, so \s is the letter s. Patterns match the whole name, so CVCV_N gives kiro_7.

Repeat Shape

Same placeholder means same character, different placeholders mean different characters. ABBA gives otto, ABAB gives coco, ABCABC gives zapzap.

Load one or more lists. Each file becomes a list named after the file. Names are split on lines, spaces, commas and semicolons, a leading @ is dropped, and duplicates merge case insensitively.

Tri-toggles: Yes = must have, No = must not have, Any = don't care. For tag boxes, press Enter to add tags.

Results: click a name to copy it, click ☆ to star it. Shape spells the name in structure letters, ready to paste into the Structure filter. Copy and Export take the whole filtered set, one name per line.

Keyboard Patterns: "Same Row" means every key sits on one keyboard row. "One hand" means every key is typed by the same hand. "Adjacent %" measures how many consecutive key-pairs are physically next to each other.
